The guide should help a reader understand what a standard addresses, what it does not address, how it relates to other specifications and where to find the responsible community. It should not duplicate an authoritative standards catalogue.

Each entry should record the publisher, version examined, scope, intended users, dependencies, implementation considerations and authoritative links. Avoid claims of compliance or endorsement unless supported by a defined assessment.

Begin with standards relevant to the first enquiry and the learning programme. Use `templates/standard.md` for new entries. No technical standards have been assessed by this starter repository.
